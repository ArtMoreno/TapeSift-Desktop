Deck icon set.

One 24x24 grid, with bold solid transport marks and 2.8px rounded strokes
for editing and telestration marks, drawn to a shared optical box of 18x18
inside it. The two treatments are balanced to read at the same visual weight
beside each other.

Every path uses currentColor. deck_icons.load() renders them at the colour
the state needs, so there is one file per shape rather than one per colour.
